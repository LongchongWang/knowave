## 💻 Claude Code

> 本周密集修复 MCP 稳定性与多会话并发问题，同时新增企业级 OTel 反馈调查、`hard_deny` 自动模式规则等实用功能，v2.1.136 是近期最大规模的 bug 修复版本（52 项变更）。

| 项目 | 内容 |
|------|------|
| 最新版本 | v2.1.138 |
| 本期区间 | v2.1.132 ~ v2.1.138 |
| 最新发布 | 2026-05-08 |
| 类型 | 功能更新 + 修复 |

**✨ 新特性**

- 🔥 `settings.autoMode.hard_deny` — 新增自动模式无条件拦截规则，可强制阻断特定操作，不受用户意图或例外规则影响，适合企业安全管控场景
- 🔥 `CLAUDE_CODE_SESSION_ID` 环境变量注入 Bash 子进程，Hooks 和 Bash 命令现在可读取 `$CLAUDE_EFFORT` 当前努力等级，方便脚本感知上下文
- 🔥 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` — 新增环境变量，可关闭全屏渲染器，让对话保留在终端原生滚动缓冲区，方便日志采集和 CI 场景
- `worktree.baseRef` 设置（`fresh` | `head`）— 控制 `EnterWorktree` 的分支基点，默认 `fresh` 恢复为 `origin/<default>`，设为 `head` 可保留未推送提交
- `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL` — 企业 OTel 用户可重新启用会话质量调查
- `claude ultrareview [target]` — 支持从 CI/脚本非交互式运行 `/ultrareview`，`--json` 输出原始结果
- `parentSettingsBehavior` 管理员级配置键，支持 SDK `managedSettings` 的策略合并模式

**🐛 修复 & 改进**

- 🔥 修复 MCP OAuth 并发刷新时 token 丢失问题 — 多个远程 MCP 服务器的用户不再需要每天重新认证
- 🔥 修复 `/clear` 后 MCP 服务器在 VS Code、JetBrains、Agent SDK 中静默消失的问题（高频痛点）
- 🔥 修复并行会话因 refresh-token 竞争导致全部 401 死锁的问题
- 修复 `--permission-mode` 在恢复 plan-mode 会话时被忽略的问题
- 修复 MCP stdio 服务器写入非协议 stdout 导致内存无限增长（可达 10GB+）的问题
- 修复 `HTTP(S)_PROXY` / `NO_PROXY` / mTLS 在 MCP OAuth 完整流程中未被遵守的问题
- 修复子 Agent 无法通过 Skill 工具发现项目/用户/插件技能的问题
- 修复 WSL2 下通过 PowerShell 回退实现 Windows 剪贴板图片粘贴
- 修复鼠标滚轮在 Cursor 和 VS Code 1.92–1.104 中滚动过快的问题
- 修复 `--resume` 在路径含下划线时找不到会话的问题
- 修复 plan mode 在存在 `Edit(...)` 允许规则时未阻止文件写入的问题

**⚠️ 破坏性变更**

- `worktree.baseRef` 默认值变更：`EnterWorktree` 的分支基点从 v2.1.128 起改为本地 `HEAD`，v2.1.133 起默认恢复为 `origin/<default>`，如需保留旧行为请显式设置 `worktree.baseRef: "head"`

## 🦀 OpenClaw

> 本周发布 v2026.5.10-beta.2，重点扩展 QA/Mantis 自动化测试能力、Discord 实时语音诊断，以及 Gateway 技能私有归档安装路径，同时修复多个 OpenAI 兼容模型和 CLI 配置持久化问题。

| 项目 | 内容 |
|------|------|
| 最新版本 | v2026.5.10-beta.2 |
| 本期区间 | v2026.5.9-beta.1 ~ v2026.5.10-beta.2 |
| 最新发布 | 2026-05-10 |
| 类型 | 功能更新 + 修复 |

**✨ 新特性**

- 🔥 QA/Mantis 新增 Telegram 直播 PR 证据自动化 — 支持 Convex 凭证租用、Crabbox 录屏、动态 GIF 预览和 PR 内联评论，大幅提升 QA 流程自动化程度
- 🔥 Gateway/Skills 新增私有技能归档上传安装路径（`skills.install.allowUploadedArchives`），受信任的 Gateway 客户端可安装 zip 打包的技能
- Discord/Voice 新增实时语音诊断，覆盖说话人轮换、播放重置、插话检测和音频截断分析
- `talk.realtime.instructions` — 运营方可在保留 OpenClaw 内置 Agent 咨询指引的同时追加实时语音风格指令
- Discord/Voice 默认使用纯 JS `opusscript` 解码器，避免非语音性能通道的原生插件编译开销
- CLI/Onboarding 改进 setup、configure、channel 命令的引导说明，终端流程现在会提示下一步有用命令

**🐛 修复 & 改进**

- 🔥 修复 OpenAI 兼容模型（oMLX/vLLM Qwen）在后续轮次中因历史 `reasoning` 字段被拒绝或卡住的问题
- 🔥 修复 `config set` / `config patch` 写入与运行时默认值相同的配置时静默丢弃的问题
- 修复 ACPX 嵌入式 ACP 后端启动探针未等待就绪即触发 `ready` 信号的问题
- 修复 Gateway 在 SIGUSR1 重启后复用旧启动快照、丢失启动后写入配置的问题
- 修复 Telegram 跨 Agent 媒体访问被拒绝的问题
- 修复非 Azure 自定义 Provider 首轮因上下文窗口过小触发压缩循环的问题
- 修复 Ollama Voice Agent 的 `tools.allow` 空列表未被遵守的问题
- 新增 `compat.strictMessageKeys` 配置，为严格 Provider 剥离 Chat Completions 消息中的 OpenAI 扩展字段
