操作技巧
01 · 入门必做
先让它自我介绍
了解能力边界，知道它能干什么、不能干什么，才不会派错任务。
💬 「请介绍你自己和你的技能」
02 · 一次配置长期受益
给它做「入职培训」
告诉它你是谁、业务方向、常用平台、偏好的输出格式，让它写进长期记忆。
🔑 明确说「写进长期记忆」
03 · 记忆管理
长期记忆 vs 每日日记
长期记忆每次都读；每日日记只读昨天和前天。30 分钟不活跃会自动重启上下文。
⚠️ 重要内容必须写进长期记忆
04 · 进阶必学
用子 Agent 并行处理
说「开子 Agent 去干这个活」，10 秒后主 Agent 回来，立刻可以再派下一个任务。
✨ 子 Agent 上下文更干净效果更好
05
复杂任务拆成小步骤
分步骤执行更可控，不要堆在一条消息里。
06
定时任务先手动跑一次
确认没问题再设定时，避免静默失败。
07
任务失败让它自己排查
让 Agent 诊断并把踩坑写进记忆。
08
用语音下指令
大象发语音，通勤路上说完它就做完了。

思维转变
👔 打工人 → 老板思维
前期说清需求，中期只盯关键节点和最终结果，其余交给它跑。
❌ 打工人事事盯进展
✅ 老板只盯结果
📄 文档化是核心资产
文档质量 = Agent 输出质量。文档清晰，所有 Agent 结果才一致可复制。
❌ 没文档差七八百万
✅ 有文档结果可复制
🌱 知识库形成复利
持续把业务知识、踩坑记录喂给 Agent，团队建公共知识库，越用越好。
❌ 不喂知识永远新手
✅ 持续喂越用越好
