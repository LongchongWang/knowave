# 云端 OpenClaw（CatClaw）入门指南：写给产品和业务同学

> 整理日期：2026-04-02  
> 适合读者：已有桌面 Claw（CatPaw Desk / 小美搭档）使用经验，想了解"云端 Claw + 大象"这种方式的产品和业务同学

---

## 一、先搞清楚：你用的桌面 Claw 和云端 Claw 有什么不同

你可能已经用过 CatPaw Desk 或小美搭档，它们都是"桌面 Claw"——打开电脑、打开 App，然后在界面里跟 AI 对话。这种方式很直观，但有一个根本限制：**你不在电脑前，它就停了**。

云端 Claw（公司内叫 **CatClaw**）解决的正是这个问题。它运行在公司的云端服务器上，不依赖你的笔记本，7×24 小时在线。你跟它交互的方式也变了——不是打开 App，而是**直接在大象里发消息**，就像跟一个同事聊天一样。

| 对比维度 | 桌面 Claw（CatPaw Desk） | 云端 Claw（CatClaw） |
|---|---|---|
| 运行位置 | 你的本地电脑 | 公司云端沙箱 |
| 交互方式 | 打开桌面 App，在 GUI 里操作 | 大象聊天窗口，发消息即可 |
| 在线时间 | 你开着电脑才在线 | 7×24 小时持续运行 |
| 定时任务 | 支持，但电脑关机就停 | 支持，且不受你是否在线影响 |
| 上手门槛 | 低，开箱即用 | 中等，需要申请并做初始配置 |
| 适合场景 | 坐在电脑前的即时任务 | 需要持续运行、定时执行的自动化任务 |

一句话总结：**桌面 Claw 是你的"即时助手"，云端 Claw 是你的"7×24 数字员工"**。

## 二、OpenClaw 是什么：背景与核心能力

### 2.1 它从哪里来

OpenClaw 是 2025 年 11 月由 PSPDFKit 创始人 Peter Steinberger 创建的开源 AI Agent 框架，最初叫 Clawdbot，后因商标问题改名为 OpenClaw。它在 2026 年 1 月底爆火出圈，2 天内获得 10 万+ GitHub Star，创下 GitHub 历史最快纪录，目前 Star 数已突破 30 万，成为 GitHub 历史上 Star 数最多的开源项目。

国内各大云厂商（阿里云、腾讯云、百度云）在 2026 年 1 月相继推出一键部署镜像，"养龙虾"成为全民热梗。美团内部基于 OpenClaw 打造了 **CatClaw** 平台，并通过大象个人助理的形式向全员开放。

### 2.2 它和普通 AI 聊天工具有什么本质区别

传统 AI 工具（ChatGPT、豆包、小美搭档）的模式是"你问它答"——你输入，它输出文字，仅此而已。

OpenClaw 的模式是"你说它做"——它不只是输出文字，而是**真正执行操作**：读写文件、控制浏览器、发送消息、执行代码、调用 API。更重要的是，它有**长期记忆**（跨会话保留上下文）和**定时执行**能力（不需要你在场）。

| 对比维度 | 传统 AI 聊天工具 | OpenClaw / CatClaw |
|---|---|---|
| 交互方式 | 你问它答，被动响应 | 能主动执行任务，有定时心跳机制 |
| 能力范围 | 文字输入 → 文字输出 | 可操作文件、浏览器、Shell、API |
| 记忆能力 | 仅限当前会话 | 本地持久化记忆，越用越懂你 |
| 运行模式 | 你在才能用 | 7×24 自主运行 |

### 2.3 核心架构（不用记，了解即可）

OpenClaw 的核心组件包括：**渠道（Channels）**负责接入大象、飞书等 IM 工具；**网关（Gateway）**是消息路由和调度中心；**智能体（Agent）**是真正"干活"的核心；**技能（Skills）**是可插拔的能力插件；**存储（Storage）**负责记忆和数据持久化。

对产品和业务同学来说，最重要的是理解：**你通过大象发消息 → 消息到达云端 Agent → Agent 调用各种工具执行任务 → 结果通过大象发回给你**。整个过程你不需要打开任何 App，手机上就能操作。

## 三、云端 CatClaw 的功能亮点

### 3.1 大象直接对话，随时随地

CatClaw 接入了大象，你的个人助理就是大象里的一个联系人。发消息给它，就像跟同事聊天一样。手机、电脑、iPad，只要能用大象，就能用 CatClaw。

### 3.2 定时任务，不需要你在场

这是云端 Claw 最核心的优势。你可以用自然语言设置定时任务，它会在指定时间自动执行并把结果发给你：

- "每天早上 9 点把今天的日程发给我"
- "每周三下午 5 点提醒我整理周报"
- "每 30 分钟抓取一次 Raptor 监控数据，有异常就通知我"

### 3.3 Skills 技能系统，能力可扩展

CatClaw 的能力来自 Skills（技能插件）。系统预装了一批常用技能，你也可以从 Skills 广场安装更多。常用的包括：

- **学城文档（meituan-km）**：读写学城文档，总结内容，搜索知识库
- **日程管理（meituan-calendar）**：查询日程、创建会议、查看忙闲
- **会议室预订（meituan-room）**：自然语言预订会议室
- **大象消息（meituan-dx）**：发送消息到指定群或个人
- **Excel 处理（xlsx）**：读取、分析、生成 Excel 表格
- **PDF 处理（pdf）**：提取 PDF 内容、生成 PDF 报告
- **图片生成（catclaw-image）**：AI 生成图片

### 3.4 长期记忆，越用越懂你

CatClaw 有持久化的记忆系统。它会记住你的偏好、历史任务、未完成事项，下次对话时不需要重新解释背景。用得越久，它越了解你的工作方式。

### 3.5 浏览器自动化，替你操作网页

CatClaw 可以控制浏览器，替你完成网页操作：登录系统、填写表单、抓取数据、截图汇报。对于需要频繁查看某个内部系统数据的业务同学，这个能力特别实用。

## 四、典型使用场景：产品和业务同学最常用的玩法

### 场景一：定时数据播报

**痛点**：每天需要多次查看 Raptor 监控大盘，手动操作繁琐且容易遗漏。

**解法**：给 CatClaw 发一条消息：

> 帮我创建一个定时任务：每 30 分钟自动抓取 Raptor（替换具体地址）日常神价会场的流量数据（峰值 QPS、平均 QPS、日/周/月环比），以简洁格式发到大象。

设置完成后，它会自动定时抓取并推送，你不需要做任何操作。

### 场景二：日程与会议管理

**痛点**：查日程、订会议室需要打开 OA 系统，操作繁琐。

**解法**：直接在大象里说：

- "帮我看看明天有哪些会议"
- "帮我订一个明天下午 3 点的会议室，4 人，在望京"
- "看看张三明天下午有没有空"

CatClaw 会直接调用日历和会议室系统完成操作，并把结果发回给你。

### 场景三：学城文档处理

**痛点**：需要快速了解一篇长文档的核心内容，或者对文档进行润色。

**解法**：把学城链接发给 CatClaw：

- "帮我总结一下这篇文档的核心内容：[学城链接]"
- "检查一下这篇文档的内容和排版，给出修改建议：[学城链接]"
- "根据这个需求文档，帮我整理一份技术方案大纲：[学城链接]"

### 场景四：数据分析与报告生成

**痛点**：拿到一份 Excel 数据，需要分析并生成报告，手动操作耗时。

**解法**：把 Excel 文件发给 CatClaw：

- "根据这个工单明细，分析一下谁处理的工单最多，生成一份汇总报告"
- "帮我把这份数据按照业务线分组，生成一个新的 Excel 表格"

### 场景五：定时提醒与任务追踪

**痛点**：重要事项容易忘记，手动设置提醒麻烦。

**解法**：

- "每天 19:00 提醒我给今天的工作收个尾"
- "每周三早上 9 点提醒我开周会"
- "30 分钟后提醒我去开会"

### 场景六：信息聚合与搜索

**痛点**：需要在多个系统（学城、大象、外网）之间来回切换查找信息。

**解法**：

- "帮我搜索一下学城里关于 XX 功能的相关文档"
- "帮我查一下最近关于 XX 的行业动态"
- "把这几个来源的信息汇总一下，生成一份摘要"

## 五、如何开始使用

### 第一步：申请 CatClaw

在大象里搜索 **Bot 管家（机器人）**，发送口令 **"许愿"**。项目团队会根据资源情况按序发放，分配完成后 Bot 管家会推送消息告知你已开通。

> 注意：目前优先面向正式员工开放，外包和实习生暂停供给。

### 第二步：找到你的个人助理

开通后，在大象里搜索"办公 AI 助理"或"个人助理"，找到带有"AI 助理"或"个人助理"标识的账号，就是你的 CatClaw 个人助理。

### 第三步：打个招呼，让它自我介绍

直接发消息："你好，介绍一下你自己，你能帮我做什么？"

它会告诉你当前已安装的技能和能力范围。

### 第四步：安装你需要的 Skills

打开 [CatClaw 控制台](https://nocode.sankuai.com/#/cat-claw)，在 Skills 页签可以看到已安装的技能，也可以从 Skills 广场安装更多。

常用推荐：
- `meituan-km`：学城文档读写
- `meituan-calendar`：日程管理
- `meituan-room`：会议室预订
- `meituan-dx`：大象消息发送
- `xlsx`：Excel 数据处理
- `pdf`：PDF 处理

### 第五步：从简单任务开始

建议从"只读"和"低风险"任务开始，熟悉后再尝试复杂操作：

1. 让它总结一篇学城文档
2. 查询明天的日程
3. 设置一个定时提醒
4. 分析一份 Excel 数据

## 六、养虾技巧

### 技巧一：换一种思维方式——想要什么结果，而不是怎么做

刚开始用 CatClaw，很多人会习惯性地问"你能做什么"，然后等它列一堆功能。更好的方式是直接说你想要的结果。

不要说"帮我查一下数据"，而是说"帮我查一下本周神价会场的 GMV，和上周相比变化了多少，用表格格式发给我"。描述越具体，结果越准确。把它当成一个新来的聪明实习生——你不需要教它怎么做，只需要说清楚你要什么。

### 技巧二：先让它自我介绍，再开始用

领到虾之后，第一件事不是急着派活，而是先问它："你现在装了哪些技能？能帮我做什么？"它会列出当前已安装的 Skills 和能力范围。这样你心里有数，不会派出它做不到的任务。

### 技巧三：主动教它记住你的偏好

CatClaw 有长期记忆，但它不会主动猜你的习惯，需要你明确告诉它。花 5 分钟做一次"入职培训"，效果会好很多：

- "我喜欢用表格格式展示数据，不要用列表"
- "发给我的报告要简洁，核心结论放最前面，不超过 200 字"
- "每次完成任务后，告诉我花了多长时间"
- "我的时区是北京时间，所有时间都用 24 小时制"

说完之后可以加一句"记住这些偏好"，它会写入记忆文件，后续任务都会自动应用。

### 技巧四：把重复性工作批量交出去

云端 Claw 最大的价值不是帮你做一件事，而是帮你把每天都要做的重复性工作自动化。建议你花 10 分钟想一想：**我每天/每周有哪些固定要做的事？** 然后一次性都设置成定时任务。

常见的可以交出去的工作：每日日程播报、数据大盘定时抓取、周报提醒、会议前提醒、竞品动态监控等。设置一次，长期受益。

### 技巧五：任务失败了，把报错直接发给它

CatClaw 执行任务时偶尔会出错。遇到这种情况，不要自己去排查，直接把报错信息或者"它说了什么"原文发给它，加一句"帮我修复这个问题"。它有自我诊断和修复能力，大多数情况下能自己解决。

如果它完全没有回复，可以发："你现在状态正常吗？帮我检查一下。"

### 技巧六：用"先做一次看看效果"来验证定时任务

设置完定时任务后，不要等到下次触发时间才知道有没有问题。直接说"手动触发一次，让我看看效果"，它会立刻执行一遍并把结果发给你。确认没问题再让它按计划跑。

### 技巧七：给它起个名字，建立工作关系

这听起来有点玄，但实际上很有用。给你的虾起一个你记得住的名字（在 Bot 管家发"给我的助理改个名称，叫 XX"），然后在对话里把它当成一个真实的工作伙伴来沟通。这样你会更自然地描述任务背景，它也能更好地理解你的意图。

### 技巧八：复杂任务拆成小步骤

如果你有一个比较复杂的需求，不要一次性把所有要求都堆在一条消息里。先让它完成第一步，确认结果对了，再继续下一步。比如：

1. 先说"帮我读取这份 Excel，告诉我有哪些字段"
2. 确认字段理解正确后，再说"好，现在按业务线分组，统计每组的总金额"
3. 最后说"把结果生成一份新的 Excel 发给我"

分步走比一次性说清楚更可靠，也更容易在中途纠偏。

### 技巧九：让它帮你写"咒语"

如果你不知道怎么描述一个任务，可以直接问它："我想每天自动汇总 XX 数据，你觉得我应该怎么跟你说？帮我写一个好用的指令模板。"它会给你一个经过优化的提示词，你以后直接用就行。

### 注意事项：信息安全

使用 CatClaw 时请注意：
- **禁止输入公司 C2 及以上敏感信息**（如用户数据、财务数据、核心算法等）
- **禁止将公司敏感信息输出到公司外**
- **禁止将员工账号认证凭据给 CatClaw**
- 如有疑问，参考公司信息安全规定

## 七、常见问题

**Q：CatClaw 和桌面 Claw（CatPaw Desk）能同时用吗？**  
A：可以，它们是两个独立的产品，定位不同，互不影响。桌面 Claw 适合坐在电脑前的即时任务，云端 Claw 适合需要持续运行的自动化任务。

**Q：CatClaw 免费吗？**  
A：大象个人助理面向个人免费使用。

**Q：助理不回消息怎么办？**  
A：在 CatClaw 控制台（nocode.sankuai.com/#/cat-claw）的聊天测试里试一下，如果也不回复，可以尝试"重启 Gateway"。

**Q：安装了 Skill 重启后丢失？**  
A：重要文件建议放在 workspace 目录下，并配置 Git 备份。

**Q：能访问外网吗？**  
A：可以访问外网，有特殊需求可联系开白名单。

**Q：怎么修改助理的名字和头像？**  
A：向 Bot 管家发送"给我的助理改个名称/头像，叫 XX"。
