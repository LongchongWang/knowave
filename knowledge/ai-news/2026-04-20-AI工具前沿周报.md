## 💻 Claude Code

> 本周重磅：v2.1.111 带来 Opus 4.7 xhigh 档位、/ultrareview 云端并行代码审查、/less-permission-prompts 自动权限白名单，以及 /tui 全屏无闪烁渲染，是近期功能密度最高的一次更新。

| 项目 | 内容 |
|------|------|
| 最新版本 | v2.1.114 |
| 本期区间 | v2.1.108 ~ v2.1.114 |
| 最新发布 | 2026-04-19 |
| 类型 | 功能更新 |

**✨ 新特性**

- 🔥 **Opus 4.7 xhigh 档位**：新增介于 high 和 max 之间的 xhigh 努力级别，通过 `/effort` 交互式滑块调节，Max 订阅用户可在 Opus 4.7 上使用 Auto 模式
- 🔥 **/ultrareview 云端并行代码审查**：调用多 Agent 并行分析当前分支或指定 PR，无需参数直接运行，也可 `/ultrareview <PR#>` 指定 GitHub PR
- 🔥 **/less-permission-prompts 自动权限白名单**：扫描历史 transcript，自动提取常见只读 Bash/MCP 工具调用，生成 `.claude/settings.json` 优先级白名单，大幅减少权限弹窗
- 🔥 **1小时 Prompt Cache TTL**：通过 `ENABLE_PROMPT_CACHING_1H` 环境变量开启，支持 API Key、Bedrock、Vertex、Foundry，显著降低长会话成本
- 🔥 **/tui fullscreen 无闪烁渲染**：新增 `/tui fullscreen` 命令切换全屏模式，解决 iTerm2 + tmux 下的终端撕裂问题
- **Session Recap 功能**：返回会话时自动提供上下文摘要，可通过 `/recap` 手动触发
- **移动端 Push 通知**：Claude 可在 Remote Control 启用时发送手机推送通知
- **Plan 文件以 prompt 命名**：计划文件现在以 prompt 内容命名（如 `fix-auth-race-snug-otter.md`），而非随机词
- **Windows PowerShell 工具**：逐步推出，可通过 `CLAUDE_CODE_USE_POWERSHELL_TOOL` 控制
- **`/skills` 支持按 token 数排序**：按 `t` 键切换，方便管理 token 预算
- **SDK 新增账户 UUID 环境变量**：`CLAUDE_CODE_ACCOUNT_UUID`、`CLAUDE_CODE_USER_EMAIL`、`CLAUDE_CODE_ORGANIZATION_UUID`，消除早期遥测事件缺少账户元数据的竞态条件

**🐛 修复 & 改进**

- 🔥 修复 MCP 工具调用在 SSE/HTTP 传输连接断开时无限挂起的问题
- 修复 `PermissionRequest` hooks 返回 `updatedInput` 未被重新检查 `permissions.deny` 规则的安全漏洞
- 修复 LSP 诊断在编辑前出现导致模型重复读取文件的问题
- 修复 `/resume` tab 补全立即恢复任意会话而非显示选择器的问题
- 修复 Bedrock/Vertex/Foundry 上 429 限速错误错误引用 status.claude.com 的问题
- 修复 Agent teams 队友请求工具权限时权限对话框崩溃的问题（v2.1.114）

## 🦀 OpenClaw

> 本周 OpenClaw 发布 2026.4.15 正式版（重磅功能更新）和 2026.4.19-beta.1/2（稳定性修复），核心亮点是默认模型升级为 Claude Opus 4.7、Gemini TTS 集成、LanceDB 云存储支持，以及 Model Auth 状态卡。

| 项目 | 内容 |
|------|------|
| 最新版本 | 2026.4.19-beta.2 |
| 本期区间 | 2026.4.15 ~ 2026.4.19-beta.2 |
| 最新发布 | 2026-04-19 |
| 类型 | 功能更新 + 修复 |

**✨ 新特性**

- 🔥 **默认模型升级为 Claude Opus 4.7**：Anthropic 模型选择、opus 别名、Claude CLI 默认值及图像理解全部切换至 Opus 4.7
- 🔥 **Gemini TTS 集成**：bundled Google 插件新增 Gemini 文字转语音支持，含语音选择、WAV 回复输出、PCM 电话输出
- 🔥 **LanceDB 云存储支持**：memory-lancedb 新增云对象存储后端，持久化记忆索引不再局限于本地磁盘
- **Model Auth 状态卡**：Control UI 概览页新增 OAuth token 健康度和 provider 限速压力一览卡，token 即将过期时显示警告
- **GitHub Copilot 嵌入向量支持**：新增 Copilot embedding provider 用于记忆搜索
- **本地模型精简模式**：`agents.defaults.experimental.localModelLean: true` 可去除 browser、cron 等重型工具，减少弱本地模型的 prompt 体积
- **Dreaming 存储模式优化**：默认改为 separate 模式，梦境阶段块写入独立文件，不再污染每日记忆文件

**🐛 修复 & 改进**

- 修复 Agent 跨 session 子 Agent 生成时账户继承错误导致的多账户混用问题
- 修复 Telegram 回调编辑错误导致更新水印卡住、阻塞新消息的问题
- 修复 WSL-to-Windows Chrome CDP 端点在严格默认配置下显示离线的问题
- 修复 Codex 累计 token 总量被误报为当前上下文使用量的问题
- 修复 BlueBubbles catchup 游标因单条消息持续失败而永久卡住的问题
- 修复 Ollama 请求因 `ollama/` 前缀导致 404 的问题
- 修复 Agent 未知工具循环调用直到超时的问题（现在默认启用 unknown-tool 防护）
- 修复 TUI 流式状态指示器在连接断开后永久卡在 streaming 状态的问题

## 💡 本期观察

> Claude Code 本周以功能密度最高的 v2.1.111 为核心，将 AI 编程工具从"辅助写代码"推向"自主执行+云端审查+权限自管理"的新阶段；与此同时，MCP 生态的国内卡位战和 WebMCP 的浏览器原生化，共同指向一个方向：AI Agent 的工具接入正在快速标准化。

**对研发同学的建议：**

- 立即升级 Claude Code 到 v2.1.111+，运行 `/less-permission-prompts` 一键生成权限白名单，减少日常开发中的权限弹窗干扰
- 开启 `ENABLE_PROMPT_CACHING_1H` 环境变量，长会话成本可显著降低，尤其适合大型代码库分析场景
- 关注 MCP Server 开发机会：国内巨头正在争相布局，现在是构建垂直领域 MCP Server 的窗口期
- 如果在用 OpenClaw，升级到 2026.4.15 后默认模型已切换为 Opus 4.7，记忆系统也更稳定

**趋势 & 认知：**

- AI 工具正从"展示性工具"变成"生产性基础设施"——hermes-agent、oh-my-claudecode 等工具的爆火，本质是开发者开始把 AI Agent 嵌入真实工作流，而非只是体验 demo
- WebMCP 值得提前关注：如果浏览器原生 AI 工具协议成为标准，未来网站将直接暴露结构化工具给 AI Agent，这将彻底改变 AI 与 Web 的交互方式，对前端和产品设计都有深远影响
